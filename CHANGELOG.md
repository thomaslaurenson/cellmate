# Changelog

## 0.1.0 - 2026-10-09

### Added

- Play FreeCell in a desktop window or a browser, in Windows 95 or XP style
- Deal the numbered Microsoft games, and the two impossible deals at -1 and -2
- Print any deal as text with the deal command
- Play with a mouse, the keyboard alone, or a finger on a touch screen
- Move runs as far as the free cells allow, and send safe cards home automatically
- Undo moves in the XP edition, and ask before resigning a game in progress
- Keep options and statistics between runs
- Draw sharp cards at any window size, beside a king who watches the cursor
